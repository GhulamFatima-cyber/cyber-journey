Day 1: Cyber Security Basics

1. Cyber Security:
Cyber security is the practice of protecting computers, networks and data from attacks or unauthorized access.

Protects:
- Networks
- Computers
- Data
- Information

2. Hacker:
A hacker is a person who gains unauthorized access to systems.

3. Types of Hackers:
- White Hat: Ethical, legal testing
- Grey Hat: No permission but no harm
- Script Kiddie: Beginner using tools
- Hacktivist: Political/social motives
- Cyber Terrorist: Large-scale damage
- Insider: Internal employee misuse
- Phisher: Tricks users for data

4. Cyber Crime:
Illegal activities using computers or internet.
Examples:
- Account hacking
- Identity theft
- Online fraud

5. Threat, Vulnerability, Risk:
- Threat: Possible danger
- Vulnerability: Weakness
- Risk: Damage caused

6. CIA Triad:
- Confidentiality: Authorized access only
- Integrity: Data remains correct
- Availability: System always accessible

7. Networking Basics:
- Default Gateway: Router to internet
- DNS: Converts domain to IP

8. Command:
- ping → checks connectivity

9. Common Attacks:
- Phishing
- Malware
- Virus
- Ransomware
- Password attacks

10. Cyber Security Roles:
- Ethical Hacker
- SOC Analyst
- Cybercrime Investigator

11. Tools:
- Linux
- Python
